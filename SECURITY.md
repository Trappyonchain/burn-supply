# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Submit it privately through [GitHub private vulnerability reporting](https://github.com/Trappyonchain/burn-supply/security/advisories/new).

If that form is unavailable, contact [@Trappyonchain on X](https://x.com/Trappyonchain) and ask for a private reporting channel. Do not send vulnerability details in a public post.

Include the affected component, security impact, reproduction steps or proof of concept, and any suggested mitigation. Do not include private keys, seed phrases, access tokens, personal data, or other secrets.

Only test systems, accounts, and assets you own or have explicit permission to test. Avoid disrupting services, accessing unrelated data, or causing loss of funds or data. Keep report details private while remediation and disclosure are coordinated.

There is no bug bounty program, and submitting a report does not create an entitlement to payment.
